# 📱 Password Manager - Mobile Application

A cross-platform native mobile client built with **React Native**, **Expo (v54)**, and **TypeScript**. This application is designed to operate securely offline, enabling users to instantly import vaults or credentials via QR code scanning and manage them directly on their device with hardware-level encryption.

---

## 🛠️ Native Technical Blueprint

- **Hardware-Secured Local Storage:** Utilizes **`expo-secure-store`** to encrypt and persist sensitive credentials locally. On iOS, data is sandboxed inside the system _Keychain_, while on Android, it leverages the hardware-backed _Keystore_ system, ensuring security compliance even in fully offline environments.
- **Camera & QR Code Provisioning:** Integrates **`expo-camera`** to provide an instantaneous, real-time scanning interface. Users can scan configuration or synchronization QR codes generated by the system to import encrypted records instantly.
- **Modern File-Based Routing:** Powered by **`expo-router`**, delivering declarative, native-feeling screen navigation (with full `safe-area-context` protection) mirroring web layout architectures.
- **Immersive UX & Animation:** Enhanced with **`expo-haptics`** for sensory vibration responses during successful biological actions (like secure scans or credential creation) alongside high-performance layout transitions driven by **`react-native-reanimated`**.
- **Ecosystem Engine integration:** Seamlessly consumes the global workspace framework via `shared-password-manager` to guarantee identical type checking, models, and cryptographic data structures used across other targets.

## 🚀 Local Execution & Development

Before booting the application, ensure you have the **Expo Go** application installed on your physical testing device, or have an Android/iOS emulator configured on your machine.

Make sure you are executing commands from the `mobile/` directory or filtering this workspace path from the monorepo root.

### 1. Launch Metro Bundler

Starts the central compilation server and opens the Expo developer interactive terminal:

```bash
npm run start
```

### 2. Device Targets Shortcuts

You can bypass the terminal menu and trigger compilation targeting specific emulator runtime structures directly:

```bash
# Run on connected Android Device or Android Studio Emulator
npm run android

# Run on macOS Xcode iOS Simulator
npm run ios
```

### 3. Cache Purge

If you run into native compilation caching conflicts or need a completely clean workspace environment initialization:

```bash
npm run clean
```
